# dsh-session-reaper

**给 DeepSeek Harness 补上可恢复的会话删除。**

DSH 的会话只能归档、不能删除：持久层没有删除接口，归档后日志仍占磁盘。这个插件补上缺失的能力——把会话移进可恢复的回收站，并回收这些会话引用过的图片附件。

- **回收站，而不是直接抹掉**：删除会把会话日志目录移到 `$DSH_HOME/deleted-sessions/<批次>/<id>/`；恢复时移回原位置，并重新挂回原工作区。
- **真正释放磁盘**：图片附件按内容寻址存放在 `$DSH_HOME/attachments/v1/objects`；只有在没有任何现存会话再引用时，才删除某个对象，共享的图片会保留。
- **两个入口**：左侧栏的完整「会话管理」面板（搜索、多选删除、回收站、彻底清除），以及每个会话行「⋯」菜单里的「删除会话…」。
- **安全设计**：路由只对 owner 开放；刚写入 60 秒内的对象跳过；扫描任何会话日志失败时整体放弃清理，不猜、不误删。

完整说明见 [docs/DETAIL.zh.md](docs/DETAIL.zh.md)。

## 安装

在「插件」页点「添加插件」，输入 `dsh-session-reaper`；或：

```sh
dsh plugin --profile <profile> add dsh-session-reaper
```

安装后重启 DSH。左侧栏出现「会话管理」，会话行菜单出现「删除会话…」。

## 数据位置

| 内容 | 位置 |
|---|---|
| 移入回收站的会话日志 | `$DSH_HOME/deleted-sessions/<批次>/<id>/session` 与 `meta.json` |
| 图片对象 | `$DSH_HOME/attachments/v1/objects/<sha256 前缀>/<sha256>` |
| 在线会话日志 | `$DSH_HOME/sessions/<项目>/<id>/` |

## 限制

- 会话日志在「清空回收站 / 彻底删除」之前仍占磁盘；那时才会删除目录。
- 删除时勾选「同时删除相关图片附件」（默认勾选）后，再恢复该会话，原图片会缺失。
- 非图片的通用文件附件（`v1/file-objects`）不在清理范围。
- 删除正在被其他进程写入的会话可能失败，错误信息会指出具体会话。
- 暂无配置项：60 秒保护窗口与回收站位置固定。
