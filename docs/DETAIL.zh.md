# 会话清理（Session reaper）

DSH 的会话只能归档、不能删除：持久层没有删除接口，归档后日志仍然占着磁盘。这个插件不修改宿主，补上缺失的能力——把会话的日志目录移进由你控制的回收站，需要时恢复，并回收只有该会话引用过的图片附件。

## 功能

### 左侧栏的会话管理面板

- 列出所有会话：标题、项目路径、最后活动时间；
- 按标题或路径搜索；「新建会话」空白草稿默认隐藏；
- 多选批量删除，或单行删除；
- 点击标题直接打开会话；
- 「回收站」标签页：恢复、彻底删除、清空回收站。

### 每个会话行菜单里的删除

会话行的「⋯」菜单新增「删除会话…」，确认后把该会话移入回收站。

### 释放磁盘

图片附件按内容寻址存放在 `$DSH_HOME/attachments/v1/objects/<sha256 前缀>/<sha256>`，相同字节只存一份。删除会话时会收集它引用的附件 id，只删除**没有任何现存会话再引用**的对象；别的会话用过的同一张图会保留。

面板里还有「清理未引用附件」：扫描所有在线会话与回收站，删除没有任何引用的对象。

## 删除过程

1. 从会话日志里读取它引用的附件 id；
2. 写一份 `meta.json`（标题、工作目录、原路径、删除时间、附件列表），把日志目录移到 `$DSH_HOME/deleted-sessions/<批次>/<id>/session`；
3. 若勾选了附件清理，扫描剩余会话并删除无人引用的对象。

恢复时把日志目录移回原位置，删除回收站条目，并把会话重新挂回与其工作目录匹配的工作区。

## 安全规则

- 所有 HTTP 路由都是认证连接上的精确路由，只有 owner 能访问；
- 只要有任何剩余会话的日志读不出来，就整体放弃附件清理——读不出的日志可能引用任何一个候选对象；
- 60 秒内新写入的对象一律跳过；
- 仍有会话引用的对象绝不删除；
- 日志被其他写入方占用时，删除会失败并给出原因，而不是强行移动。

## 限制

- 会话日志在回收站条目被彻底删除前仍占磁盘；
- 勾选附件清理后，之后再恢复该会话，文字历史还在但图片会缺失；
- 非图片的通用文件附件（`v1/file-objects`）不在清理范围；
- 暂无配置项：回收站位置与 60 秒保护窗口固定；
- 子代理来源的会话行不显示。

## 数据位置

| 内容 | 位置 |
|---|---|
| 回收站中的会话日志 | `$DSH_HOME/deleted-sessions/<批次>/<id>/session` |
| 回收站元数据 | `$DSH_HOME/deleted-sessions/<批次>/<id>/meta.json` |
| 图片对象 | `$DSH_HOME/attachments/v1/objects/<前缀>/<sha256>` |
| 在线会话日志 | `$DSH_HOME/sessions/<项目>/<id>/` |

## 卸载

停用或卸载插件不会动回收站目录；卸载前请先在面板里恢复条目，或手动把目录移回。想要空间就先把回收站清空。
